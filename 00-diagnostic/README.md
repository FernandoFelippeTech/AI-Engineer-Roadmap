## 3. Observed Evidence

### Conditional Logic

Basic conditional reasoning was demonstrated successfully.

Given sequential conditional statements, it was possible to:

- follow variable state changes;
- evaluate conditions in execution order;
- calculate the resulting output;
- explain the reasoning behind the result.

**Current status:** Promising foundation — formal validation still required.

---

### Variables and State

Basic understanding of variables and value mutation was demonstrated while tracing code.

Example reasoning successfully followed a sequence similar to:

`10 → 12 → 24`

This indicates an initial understanding that a variable can change during program execution.

**Current status:** Basic understanding observed — formal validation still required.

---

### Loops and Iteration

A significant knowledge gap was identified around iteration.

Concepts requiring reinforcement include:

- the role of the iteration variable;
- how `for` works;
- the meaning of `in`;
- how `range()` generates a sequence;
- how values change between iterations;
- how loops affect program state;
- reasoning about loop output.

**Current status:** Reinforcement required.

**Priority:** High.

---

## 4. Problem-Solving

Current evidence suggests that reasoning is stronger when code execution can be followed sequentially.

More practice is required when the solution involves:

- repeated execution;
- constructing an algorithm independently;
- deciding which control structure to use;
- translating a problem statement into code;
- maintaining state across iterations.

These areas will be explicitly developed during Phase 01.

## 5. AI Assistance Baseline

AI is currently used heavily during programming activities.

Estimated starting dependency:

`4–5 / 5`

This does not mean AI usage should be eliminated.

The objective is to distinguish between:

**AI as a productivity tool**

and

**AI as a prerequisite for solving the problem.**

For foundational competencies, the target is:

`≤ 2 / 5 assistance`

before considering the competency reliably validated.

## 7. Initial Diagnostic Decision

### Current Starting Phase

**Phase 01 — Programming Foundations**

### Immediate Focus

**Loops and Iteration**

The roadmap should not restart every programming concept blindly from zero.

Instead, Phase 01 will combine:

1. targeted diagnostic questions;
2. structured study where gaps exist;
3. practical exercises;
4. reduced-assistance challenges;
5. competency assessments.

Previously understood concepts can be validated faster.

Weak concepts receive deeper study and practice.
