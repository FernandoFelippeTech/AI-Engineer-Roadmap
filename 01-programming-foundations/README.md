# Phase 01 — Programming Foundations

> Build reliable programming fundamentals before advancing to software engineering and AI-specific topics.

---

## Objective

Develop the programming reasoning and Python foundations required for the rest of the AI Engineer Roadmap.

This phase is competency-based.

Time spent studying does not determine progression.

Progression requires demonstrated understanding and practical application.

---

# Study Method

Typical study availability:

**~1 hour per day**

Sessions will intentionally combine different learning formats to avoid a passive or repetitive study routine.

Depending on the topic, a session may include:

- Concept explanation
- Conversation and reasoning
- Video lessons
- Official documentation
- Code reading
- Guided coding
- Independent coding
- Debugging
- Small challenges
- Technical questions
- Practical experiments
- Assessments

Not every session must contain every format.

The format should be selected according to the competency being developed.

---

# Learning Cycle

Each major competency follows this cycle:

`Understand → Observe → Practice → Apply → Explain → Assess → Validate`

### 1. Understand

Develop a conceptual understanding of the topic.

### 2. Observe

Read or trace working examples.

### 3. Practice

Solve guided exercises.

### 4. Apply

Solve problems with progressively less assistance.

### 5. Explain

Explain the concept and reasoning without relying on memorized definitions.

### 6. Assess

Complete an assessment designed to expose gaps.

### 7. Validate

A competency is marked as validated only when sufficient independent understanding has been demonstrated.

---

# Assistance Strategy

AI may be used during the learning process.

However, assistance should progressively decrease.

The objective is not:

> "Never use AI."

The objective is:

> "Be able to reason and solve foundational problems without requiring AI."

During independent challenges and assessments, assistance may be restricted.
