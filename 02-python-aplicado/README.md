# Fase 02 — Python Aplicado

## Objetivo

Transformar os fundamentos de programação da fase anterior em capacidade prática de desenvolver programas Python mais organizados, reutilizáveis e próximos de aplicações reais.

Ao concluir esta fase, devo conseguir estruturar um pequeno projeto Python, trabalhar com arquivos e dados, organizar código em módulos, gerenciar dependências, tratar exceções e utilizar orientação a objetos quando ela realmente fizer sentido.

---

## Pré-requisito

Antes de concluir esta fase, os principais fundamentos da Fase 01 devem estar validados.

Conceitos desta fase podem ser apresentados durante o aprendizado anterior quando forem úteis, mas sua validação ocorrerá aqui.

# Projeto 02 — Aplicação Python Estruturada

Após validar os módulos desta fase, será desenvolvido um projeto Python mais próximo de uma aplicação real.

O projeto deverá utilizar, quando apropriado:

- múltiplos arquivos e módulos;
- leitura ou persistência de dados;
- JSON;
- tratamento de exceptions;
- dependências externas;
- ambiente virtual;
- organização clara de responsabilidades;
- orientação a objetos somente quando houver justificativa;
- debugging e refatoração.

O problema específico será definido no momento do projeto para permitir que ele reutilize competências já validadas e exija decisões próprias de implementação.

---

## Resultado esperado

Ao concluir esta fase, devo conseguir desenvolver e organizar uma aplicação Python pequena sem depender de um único arquivo ou de código pronto, compreender suas dependências, investigar problemas e explicar as principais decisões de implementação.

Essa competência servirá de base para APIs, backend, bancos de dados e aplicações de AI Engineering nas próximas fases.
