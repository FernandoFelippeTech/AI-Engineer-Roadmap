# AI Engineer Roadmap

Roadmap prático de preparação para minha primeira oportunidade profissional como **AI Engineer Junior**.

Este repositório documenta uma trilha progressiva baseada em competências técnicas recorrentes em vagas de entrada na área de AI Engineering, combinadas com as dependências necessárias para desenvolvê-las de forma consistente.

O objetivo não é apenas estudar tecnologias, mas **demonstrar competência por meio de exercícios, debugging, checkpoints e projetos**.

---

## Objetivo profissional

Alcançar o marco:

# 🏁 AI Engineer Junior Ready

Esse marco representa:

> **Pronto para iniciar candidaturas a vagas de AI Engineer Junior.**

Para alcançá-lo, será necessário concluir e validar os fundamentos técnicos, desenvolver projetos demonstráveis e passar por um checkpoint técnico final.

## Fases

### 00 — Diagnóstico

Avaliação do ponto de partida e identificação de lacunas técnicas.

### 01 — Fundamentos de Programação

Lógica, variáveis, operadores, condicionais, loops, funções, estruturas de dados, erros e debugging.

**Entrega:** Projeto 01 — Python e Lógica

### 02 — Python Aplicado

Organização de código, módulos, arquivos, JSON, exceptions, ambientes virtuais, dependências e OOP essencial.

### 03 — Ferramentas de Engenharia

Terminal, Git, GitHub, branches, merge, conflitos, documentação e testes.

**Entrega:** Projeto 02 — Aplicação Python Estruturada

### 04 — APIs e Backend

HTTP, REST, consumo de APIs, autenticação, FastAPI, Pydantic e testes de API.

### 05 — Dados e SQL

SQL, modelagem relacional, PostgreSQL, integração com Python, persistência e Pandas essencial.

**Entrega:** Projeto 03 — API + FastAPI + PostgreSQL

### 06 — Fundamentos de IA e LLMs

Machine Learning essencial, Transformers, LLMs, tokens, contexto, Prompt Engineering, Context Engineering, Structured Outputs e avaliação.

**Entrega:** Projeto 04 — Aplicação com LLM

### 07 — Embeddings e Busca Semântica

Embeddings, similaridade, chunking, metadata, vector databases, indexação e retrieval.

### 08 — RAG

Ingestão, indexação, retrieval, contexto, geração fundamentada, fontes, avaliação e diagnóstico.

**Entrega:** Projeto 05 — Sistema RAG

### 09 — Agentes e Orquestração

Tool Calling, workflows, estado, agentes, LangChain, LangGraph, observabilidade e avaliação.

**Diferencial opcional:** MCP

### 10 — Entrega e Produção Básica

Docker, Docker Compose, cloud, deploy, logs, health checks, CI/CD, GitHub Actions, segurança e custos.

## Projetos

O aprendizado será acompanhado por projetos progressivos.

| Projeto | Objetivo |
|---|---|
| Projeto 01 | Demonstrar lógica e fundamentos de Python |
| Projeto 02 | Construir uma aplicação Python estruturada |
| Projeto 03 | Integrar FastAPI e PostgreSQL |
| Projeto 04 | Construir uma aplicação real utilizando LLM |
| Projeto 05 | Construir e avaliar um sistema RAG |
| Projeto de Portfólio | Integrar competências de AI Engineering em uma aplicação demonstrável |

O projeto de portfólio não precisa utilizar todas as tecnologias estudadas.

A arquitetura deverá ser determinada pelo problema, evitando complexidade adicionada apenas para aumentar a quantidade de ferramentas utilizadas.

## Método de estudo

Cada fase poderá combinar:

- conceitos;
- documentação;
- exemplos;
- exercícios guiados;
- exercícios independentes;
- debugging;
- implementação;
- checkpoints;
- projetos;
- avaliações sem assistência.

O roadmap não considera um conteúdo dominado apenas porque foi lido ou estudado.

---

## Validação

Os módulos utilizam os seguintes estados:

| Estado | Significado |
|---|---|
| ⬜ Não iniciado | O conteúdo ainda não começou |
| 🟦 Em estudo | O conteúdo está sendo aprendido e praticado |
| 🟨 Em validação | A competência está sendo testada |
| ✅ Validado | A competência foi demonstrada |

`[x]` representa uma competência demonstrada, não apenas conteúdo consumido.

## Uso de IA durante o aprendizado

Ferramentas de IA podem ser utilizadas para apoiar:

- explicações;

## Escopo

Este roadmap termina no ponto de preparação para a **primeira vaga de AI Engineer Junior**.

Não fazem parte do escopo obrigatório desta trilha:

- preparação para nível Pleno ou Sênior;
- Machine Learning acadêmico aprofundado;
- treinamento avançado de modelos;
- fine-tuning avançado;
- sistemas distribuídos complexos;
- Kubernetes avançado;
- MLOps avançado;
- arquiteturas multi-agent avançadas.

Esses temas poderão fazer parte de ciclos posteriores de desenvolvimento profissional.

---

## Critério final

A conclusão das matérias, isoladamente, não encerra o roadmap.

O marco final exige:

```text
Fundamentos validados
        +
Projetos progressivos
        +
Projeto de portfólio
        +
GitHub apresentável
        +
Checkpoint técnico final
        ↓
🏁 AI Engineer Junior Ready
```

Ao atingir esse marco, começa uma nova etapa:

**candidaturas para vagas de AI Engineer Junior.**
