# Fase 03 — Ferramentas de Engenharia

## Objetivo

Desenvolver as práticas de engenharia de software necessárias para trabalhar com projetos reais, colaborar por meio do Git e GitHub, utilizar o terminal com autonomia e manter código versionado, documentado e testável.

Esta fase transforma o uso das ferramentas em competência prática. Algumas delas já serão utilizadas durante o próprio roadmap, mas somente serão consideradas validadas quando eu conseguir utilizá-las e explicar seu funcionamento com autonomia.

## Validação prática

Parte da validação desta fase ocorrerá no próprio desenvolvimento do roadmap e dos projetos seguintes.

Além disso, será realizado um exercício controlado envolvendo:

1. criação de uma branch;
2. alteração de código;
3. execução de testes;
4. revisão com `git diff`;
5. commit;
6. criação de Pull Request;
7. merge;
8. geração e resolução de um conflito proposital.

O objetivo é demonstrar compreensão do fluxo, e não apenas reproduzir uma sequência de comandos.

---

## Resultado esperado

Ao concluir esta fase, devo conseguir trabalhar com um projeto versionado utilizando terminal, Git e GitHub, revisar minhas próprias alterações, criar testes básicos, documentar o projeto e utilizar um fluxo de desenvolvimento próximo daquele encontrado em uma equipe de software.

Essas práticas serão utilizadas continuamente nas fases e projetos seguintes.
