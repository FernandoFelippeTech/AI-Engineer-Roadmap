## Validation System

Progress is based on demonstrated competency rather than content consumption.

### 🟢 Validated

The concept can be explained and applied with sufficient independence.

**Decision:** Continue to the next competency.

### 🟡 Partial

The core idea is understood, but specific gaps remain.

**Decision:** Targeted review followed by reassessment.

### 🔴 Reinforcement Required

Fundamental gaps prevent reliable application.

**Decision:** Reinforcement exercises and a new assessment before progressing.

- Code reading
- Debugging

### Project Validation

Used to verify that multiple competencies can be integrated into a working system.

### Final Technical Validation

Used near the end of the roadmap to simulate technical evaluation for AI Engineering roles.

## Assistance Levels

The goal is not to eliminate AI usage, but to develop the ability to reason, implement and debug without depending on AI for every step.

| Level | Description |
|---|---|
| 5 | Unable to progress without direct AI assistance |
| 4 | Heavy assistance required |
| 3 | Moderate assistance |
| 2 | Occasional guidance |
| 1 | Mostly independent |
| 0 | Fully independent for the evaluated task |
