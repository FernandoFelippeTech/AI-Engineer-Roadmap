# Fase 01 — Fundamentos de Programação

## Objetivo

Construir uma base sólida de lógica de programação antes de avançar para Python aplicado, APIs, bancos de dados e AI Engineering.

Ao concluir esta fase, devo conseguir compreender um problema simples, transformá-lo em etapas lógicas, implementar uma solução em Python, testar o comportamento do código e identificar erros básicos.

---

## Como estudar esta fase

Cada módulo pode combinar diferentes formas de estudo:

1. Explicação do conceito
2. Exemplos comentados
3. Documentação ou material externo quando necessário
4. Exercícios guiados
5. Exercícios independentes
6. Leitura e interpretação de código
7. Debugging
8. Miniavaliação

Nem todos os módulos precisam utilizar todas essas etapas.

O objetivo não é apenas consumir conteúdo, mas demonstrar a competência na prática.

---

## Critério de validação

Os estados utilizados são:

- ⬜ Não iniciado
- 🟦 Em estudo
- 🟨 Em validação
- ✅ Validado

Um módulo recebe `✅ Validado` somente quando eu consigo demonstrar a competência esperada em exercícios ou avaliações práticas.

Consultar uma resposta, documentação ou IA durante o aprendizado é permitido.

Quando uma atividade estiver identificada como **avaliação sem assistência**, a solução deve ser realizada sem ajuda externa.

Se eu precisar de ajuda significativa durante uma avaliação, o conteúdo volta para revisão antes de uma nova tentativa.

# Projeto 01 — Python e Lógica

Após validar os módulos, será desenvolvido um pequeno projeto que utilize as competências da fase em conjunto.

O projeto deverá exigir:

- entrada e transformação de dados;
- condicionais;
- loops;
- funções;
- estruturas de dados;
- tratamento básico de erros;
- organização lógica do código;
- testes manuais de diferentes cenários.

O projeto específico será definido quando as competências necessárias estiverem validadas, evitando escolher uma atividade que seja artificialmente fácil apenas para cumprir o roadmap.

## Resultado esperado

Ao concluir esta fase, devo conseguir receber um problema de programação de nível iniciante, raciocinar sobre a solução, escrever uma implementação em Python, testar o resultado, investigar erros e explicar como o código funciona.

Essa base será utilizada nas fases seguintes do roadmap.
